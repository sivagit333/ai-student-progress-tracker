## 📌 Project Overview

AI Student Progress Tracker is a web-based student performance management
application built with Python and Streamlit.

The application allows users to manage student records, analyze academic
performance, and generate learning recommendations based on students'
subject-wise scores.

### Key Capabilities

- 👨‍🎓 Student management
- ➕ Add student records
- ✏️ Update student information
- 🗑️ Delete student records
- 📊 Performance analysis
- 📈 Subject-wise performance visualization
- 💡 Learning recommendations
- 🗄️ Supabase database integration
- 🔐 Row Level Security (RLS)
- ☁️ Streamlit Cloud deployment
