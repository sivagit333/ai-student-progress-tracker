# 📊 AI Student Progress Tracker

An interactive student performance tracking and analysis dashboard built using **Python, Streamlit, Pandas, and Supabase**.

The application allows instructors to manage student records, analyze academic performance, and generate personalized learning recommendations.

## 📌 Project Overview

AI Student Progress Tracker is a web-based student performance management application built with Python and Streamlit.

The application allows instructors to manage student records, analyze academic performance, and generate learning recommendations based on students' subject-wise scores.

### Key Capabilities

- 👨‍🎓 Student management
- ➕ Add student records
- ✏️ Update student information
- 🗑️ Delete student records
- 📊 Performance analysis
- 📈 Subject-wise performance visualization
- 💡 Learning recommendations
- 🗄️ Supabase database integration
- 🔐 Row Level Security (RLS)
- ☁️ Streamlit Cloud deployment

---

## ✨ Features

### 👨‍🎓 Student Management

- Add new students
- Edit existing student information
- Delete student records
- Store student data in Supabase
- Prevent duplicate Student IDs

### 📊 Performance Dashboard

- Total number of students
- Overall average score
- Number of excellent performers
- Number of students needing improvement
- Complete student performance table

### 👤 Individual Student Analysis

Select a student and view:

- Python score
- SQL score
- Project score
- Average score
- Performance level
- Subject performance chart

### 🤖 Learning Recommendations

The application automatically identifies the student's weakest subject and provides a learning recommendation based on their performance.
